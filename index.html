Foreign Language Text Analyzer script

Personal project | 2024

GitHub

What is it?

A simple script that I wrote to help streamline the most time consuming part of learning a foreign language: processing new vocabularly.

SpaCy Natural Language Processing models are used to process and lemmitize words, which are then organized for export to flashcards.


My role:

After becoming interested in artificial intelligence during my Masters Thesis, I decided to continue exploring the potential of natural language processing.

The program takes a foreign-language PDF and processes the words, creating a frequency list accompanied with an example sentence of that word. A Google Translate plugin is then used to generate translations for each word. From there, the CSV file can be easily imported into Anki flashcards for memorization.


Technology / Team / Time:

This was a solo project, using SpaCy language models and Python.

An example of what the output CSV file would look like. In this form, it is very simple to import these new words as flashcards into Anki.

Masters Thesis Project

Game Design and Production MA | Aalto University, Finland | 2022

Aalto docs

What is it?

This program uses neural language models to automatically classify, label and highlight areas of interest to the games user researcher.

In brief, remote playtesting usually requires the manual review of tens of hours of footage, and we wanted to expedite that process.

Transcripts were generated from playtest videos, which were then analyzed by a sentence classifier trained with manually labelled data and the classified results (in the form of video timestamps) are then passed to the user researcher, sorted by sentiment and intensity.


My role:

Wrote parts the code, ran the study to compare the software against a manual approach.


Technology / Team / Time:

Developed using Python and Hugging Face language models, while I was working at HypeHype mobile game company as a Player Analyst.

Developed for my masters thesis, it was designed to improve the user research process at HypeHype. Compared in a study against a manual approach, and was shown to greatly increase the speed of insight-collection, allowing a larger turnover of user tests.
