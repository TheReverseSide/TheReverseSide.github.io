Foreign Language Text Analyzer

Helsinki, Finland, 2024

GitHub


After becoming interested in machine learning during my Masters Thesis, I decided to continue exploring the potential of natural language processing.


Since I love learning languages, I thought I would create a tool to help streamline one of the most time consuming parts of learning a language: processing new vocabulary.


Objective: To take a foreign-language PDF and create a list of all words, lemmitize them (put them in their base-form), then remove any words I already know. From there, the program creates a frequency list of the words, accompanied with an example sentence of that word. A Google Translate plugin is then used to generate translations for each word. From there, the CSV file can be easily imported into Anki flashcards for memorization.
