Foreign Language Text Analyzer

GitHub


After becoming interested in ML during my Masters Thesis, I decided to continue exploring the potential of NLP.


Since I love learning languages, I thought I would create a tool to help streamline one of the most time consuming parts of learning a langauge: processing new vocabulary.


Objective: To take a foreign-language PDF and create a list of all words, lemmitize them (put them in their base-form), then remove any words I already know. From there, the program creates a frequency list of the words, accompanied with an example sentence of that word. A Google Translate plugin is then used to generate translations for each word. From there, the CSV file can be easily imported into Anki flashcards for memorization.

Masters Thesis Project, Game Design and Production, Aalto University

Aalto docs


Remote playtesting usually requires the manual review of tens of hours of footage, leveraging recent advances in AI, this system greatly increases the speed of insight-collection, allowing a larger turnover of user tests, at the cost of a slightly reduced number of insights found per playtest.

In brief, transcripts were generated from the playtest videos, which were then analyzed by a sentence classifier trained with manually labelled data and the classified results (in the form of video timestamps) are then passed to the user researcher, sorted by sentiment and intensity.
